# Clinical knowledge sources: licensing note

**Decision (2026-10-11).** Lumina is not going to be published, so all five knowledge sources stay in the RAG index: NIMH, Wikipedia, NHS, Mayo Clinic and HelpGuide. These sources feed the chatbot's knowledge base only. They are not used in the market analysis.

**Revisit before any public release.** A deployed chatbot that shows stored text republishes it. A web search on 2026-10-11 suggested the following; it is not legal advice.

| Source | What the terms appear to say |
|---|---|
| NIMH | Public domain, text only. |
| Wikipedia | CC BY-SA; attribution required. |
| NHS England | Open Government Licence; attribution required. The nhs.uk terms page itself was not confirmed. |
| Mayo Clinic | No reproduction without written consent ([terms](https://www.mayoclinic.org/about-this-site/terms-use-licensed-content)). |
| HelpGuide | Republication requires a paid permission request ([reprints](https://www.helpguide.org/contact-us)). |

Before a release, each of these terms would need to be checked and permission obtained where required.
